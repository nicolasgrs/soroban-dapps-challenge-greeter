# Deploy and run the greeter contract

**Run the container**
```sh
bash run.sh
```

**Deploy on testnet or futurenet**
```sh
bash initialize.sh testnet
```
Check the contract on stellar.expert (testnet only)

**Run Hello World**
```sh
bash hello.sh 
```
Check the contract on stellar.expert (testnet only)

**Run Increment**
```sh
bash incr.sh
```
Check the contract on stellar.expert (testnet only)
